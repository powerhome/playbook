The advanced variant leverages Tiptap to unlock additional UI options (e.g., consolidated nav toolbar, styling, etc.) as well as several extensions (see [Tiptap docs](https://tiptap.dev/extensions) for more). To leverage this variant, Tiptap __must be installed__ in your project at `3.0.7` (same version as Nitro RTE). Complete docs for using the library can be found [here](https://tiptap.dev/). To get started with this variant, see the Code Example below for required imports as well as the basic setup.

NOTE: TipTap v3 StarterKit includes Link and Underline. Do not also register `@tiptap/extension-link` / `@tiptap/extension-underline` unless you disable them on StarterKit first. Prefer `StarterKit.configure({ trailingNode: false })` so saved HTML does not pick up TipTap’s synthetic trailing empty paragraph.
