The `active_style` prop customizes the selected option. `background_color` and `font_color` can be set together or on their own.

`background_color` sets the background of the selected item, including its hover state. **Type**: String | **Values**: bg_light | white | **Default**: primary

`font_color` sets the font color of the selected item. **Type**: String | **Values**: primary | all [Playbook Text Colors](https://playbook.powerapp.cloud/global_props/colors) | **Default**: white
