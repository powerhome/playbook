`group_separators` (default `false`) mirrors React `groupSeparators`: a `2px` `$input_border_default` stroke on the last sibling of each nested child group (replacing the default border; inset to the outermost group it closes, full-bleed when that is a year).

This example defaults to **2022 → Q1 → January** open (May/Q2 collapsed) and **2023** open to its quarters, matching the React example. Expanded last-sibling parents defer to the last visible descendant.
