`group_separators` (default `false`) mirrors React `groupSeparators`: a `2px` `$input_border_default` bottom border on the last sibling row of each nested group that has no further children in the data tree.

Expand nested rows to see separators between sibling groups. Note that when a last-sibling parent is collapsed, the separator stays on its leaf rows (which are hidden) until those rows are expanded again.
