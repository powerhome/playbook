Build React forms by pairing Playbook form kits with [react-hook-form](https://react-hook-form.com/). Use `register` for kits that forward a ref and call `onChange` with an event (Select, Textarea, Dropdown, Typeahead, Multi Level Select). Use `Controller` for controlled kits or kits whose `onChange` sends a value instead of an event (Text Input, Checkbox, Date Picker, Time Picker, Phone Number Input, Star Rating).

Pick an input below to see Defaults, Validation, Default Values, and Multi-Column layout patterns one field at a time.
