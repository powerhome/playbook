The `showTimezone`/`show_timezone` prop can be used to show the timezone as well. This is set to false by default. **NOTE**: This prop must be used in conjunction with the `timezone` prop to specify which timezone to display.

The `timezone` prop accepts both [IANA timezone identifiers](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) (e.g. `America/New_York`) and [ActiveSupport timezone names](https://api.rubyonrails.org/classes/ActiveSupport/TimeZone.html) (e.g. `Eastern Time (US & Canada)`).
